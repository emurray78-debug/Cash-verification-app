# Cash Drawer Count App

A mobile-friendly beginning/end-of-shift cash drawer calculator.

## GitHub Pages setup

1. Create a new GitHub repository.
2. Upload all files from this folder to the root of the repository.
3. Make sure the main page is named exactly `index.html`.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then click **Save**.
7. Open the published GitHub Pages link in Safari on iPhone.
8. Tap **Share → Add to Home Screen**.

The app saves the current form automatically on the device and works offline after it has been opened once.
